# Deja Chamados

> Documentação oficial do módulo de gerenciamento de chamados da Deja Platform.

## Objetivo

Prover uma base de documentação técnica, funcional e operacional do módulo Chamados integrado à Deja Platform.

## Escopo

O módulo Chamados cobre o fluxo completo de atendimento, incluindo:

- clientes;
- chamados;
- atribuição de responsáveis;
- status e prioridade;
- comentários;
- anexos;
- timeline;
- portal do cliente;
- fila de atendimento;
- dashboard;
- controle de prazo/SLA;
- autorização por perfil.
