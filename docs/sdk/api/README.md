# Public Module SDK API Reference

## Status

Official

---

# Purpose

This directory contains the normative specification of every public API provided by the Deja Platform Public Module SDK.

Each document defines the official contract supported by the platform.

Only the APIs documented in this directory are covered by compatibility guarantees.

---

# Public APIs

- Module Command API
- Module Service API
- Capability API
- Module Extension API
- Module Configuration API
- Module Configuration Provider API
- Module Configuration Observer API

---

# Compatibility

Applications and modules must depend exclusively on the APIs documented in this directory.

Kernel implementation details are intentionally excluded from this documentation.
