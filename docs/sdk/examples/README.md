# Public Module SDK Examples

## Status

Official

---

# Purpose

This directory contains the official examples of the Deja Platform Public Module SDK.

Each example demonstrates the minimal recommended usage of a single public API.

Examples intentionally use only the Public Module SDK.

No Kernel internals or private APIs are referenced.

---

# Available Examples

- Module Command API
- Module Service API
- Capability API
- Module Extension API
- Module Configuration API
- Module Configuration Provider API
- Module Configuration Observer API

---

# Design Principles

Every example follows the same principles:

- Minimal implementation.
- One concept per example.
- Public SDK only.
- No internal implementation details.
- Ready to be used as a reference when developing new modules.

---

# Relationship with the SDK

The examples complement the API Reference and the Development Guides.

They are informative and educational, while the API Reference remains the normative specification of the Public Module SDK.
