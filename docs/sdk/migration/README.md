## Status

Reserved

# Purpose

This directory contains migration guides between versions of the Public Module SDK.

Migration guides describe compatibility changes, deprecated APIs, recommended migration paths and upgrade considerations for module developers.

---

# Current Status

The Public Module SDK v1 is the first official release.

No migration guides are currently required.

This directory is intentionally reserved for future SDK versions.

---

# Compatibility Policy

Backward compatibility applies only to APIs officially documented by the Public Module SDK.

Kernel implementation details remain internal and may evolve without notice.
