# Purpose

This directory contains the official guides for developing modules for the Deja Platform.

Unlike the API Reference, these documents explain concepts, workflows, recommended practices and the expected module development process.

# Relationship with the SDK

The guides complement the Public Module SDK by explaining how the public APIs should be used during module development.

The API Reference remains the normative specification of the SDK.
