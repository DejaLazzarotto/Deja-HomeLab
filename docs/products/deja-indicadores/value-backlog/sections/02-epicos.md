# Épicos

## Objetivo

Este documento define os Épicos da Deja Indicadores.

Cada Épico representa uma grande entrega de valor para o cliente e deriva diretamente das capacidades de negócio identificadas no Mapa de Capacidades.

Os Épicos servem como base para a definição das Features, das Histórias, da Arquitetura Funcional e da implementação do produto.

---

# EP-001 — Gestão de Empresas

## Objetivo

Permitir o cadastro, organização e administração das empresas atendidas pela Deja Indicadores.

### Escopo

- cadastro de empresas;
- informações institucionais;
- unidades organizacionais;
- situação cadastral;
- parametrizações iniciais.

Relaciona-se às capacidades:

- Gestão de Empresas

## Organização

Os Épicos representam o primeiro nível de planejamento funcional da Deja Indicadores.

A evolução do produto ocorrerá por meio do detalhamento de cada Épico em Features, posteriormente decompostas em Histórias implementáveis.
