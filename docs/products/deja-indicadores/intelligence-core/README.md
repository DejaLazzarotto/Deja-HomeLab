# Intelligence Core

O Intelligence Core constitui o núcleo arquitetural da Deja Indicadores.

Este componente estabelece toda a infraestrutura compartilhada responsável pela integração, coordenação e execução dos Engines de inteligência do produto.

O Core não implementa regras de negócio específicas. Sua responsabilidade é fornecer os contratos, serviços, runtime e mecanismos institucionais necessários para que os Engines operem de forma integrada, desacoplada e evolutiva.
