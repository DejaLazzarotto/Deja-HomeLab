# 03. Organização

## Objetivo

Esta seção descreve a organização arquitetural do API Gateway dentro da Deja Platform.

A organização define como os elementos da capacidade são estruturados, suas responsabilidades e os relacionamentos entre os componentes envolvidos.

---

# Visão organizacional

O API Gateway é organizado como uma capacidade transversal da plataforma.

Sua estrutura separa responsabilidades de:

- exposição;
- controle;
- resolução;
- integração;
- observabilidade;
- governança.

Essa separação permite evolução independente e manutenção simplificada.
