# Hosted Apps

## Visão Geral

A Hosted Apps estabelece a capacidade institucional responsável pela hospedagem, implantação, gerenciamento, isolamento, execução e operação das aplicações hospedadas na Deja Platform.

Esta capacidade define como aplicações internas da plataforma, aplicações comerciais, aplicações desenvolvidas por clientes e aplicações de terceiros são executadas de forma segura, escalável e totalmente integrada ao ecossistema institucional.

A Hosted Apps não implementa regras de negócio das aplicações hospedadas.

Sua responsabilidade consiste em fornecer toda a infraestrutura institucional necessária para que aplicações possam ser executadas dentro da plataforma preservando isolamento, segurança, observabilidade, governança e administração operacional.

## Objetivos

A Hosted Apps define:

- modelo institucional de hospedagem
- ciclo de vida das aplicações
- ambientes de execução
- gerenciamento operacional
- deployment institucional
- isolamento entre aplicações
- integração com capacidades institucionais
- administração operacional
- rastreabilidade
- governança
- evolução da infraestrutura de hospedagem

---

## Escopo

Esta capacidade contempla:

- hospedagem institucional
- registro de aplicações
- execução das aplicações
- isolamento
- gerenciamento operacional
- deployment
- atualização
- versionamento
- monitoramento
- integração institucional

Não fazem parte desta capacidade:

- desenvolvimento das aplicações
- regras de negócio
- interfaces específicas das aplicações
- funcionalidades de domínio
