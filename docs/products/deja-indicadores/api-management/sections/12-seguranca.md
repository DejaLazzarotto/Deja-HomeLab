# 12. Segurança

## Objetivo

Esta seção define os princípios e mecanismos de segurança aplicados ao API Management dentro da Deja Platform.

O objetivo é garantir que o gerenciamento, publicação e consumo das APIs ocorram de forma segura, controlada e integrada com a arquitetura institucional de Security.

---

# Visão Geral

A segurança das APIs é uma responsabilidade compartilhada entre o API Management, Security e API Gateway.

Cada componente possui responsabilidades específicas.
