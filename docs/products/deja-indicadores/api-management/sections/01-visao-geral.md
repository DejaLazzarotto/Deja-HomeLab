# 01. Visão Geral

## Objetivo

Esta seção apresenta a visão geral do API Management dentro da arquitetura da Deja Platform.

O API Management representa a capacidade institucional responsável por administrar o ciclo completo das APIs, garantindo que elas sejam criadas, publicadas, consumidas e evoluídas de forma controlada.

---

## Contexto Arquitetural

A Deja Platform utiliza APIs como mecanismo oficial de exposição de capacidades internas e integração com consumidores externos.

Com a introdução do API Gateway, a plataforma estabeleceu uma camada controlada de acesso às capacidades internas.

O API Management complementa essa arquitetura fornecendo os mecanismos necessários para administrar essas APIs ao longo de sua existência.
