# 04. Modelo de Gerenciamento

## Objetivo

Esta seção define o modelo arquitetural utilizado pelo API Management para administrar as APIs da Deja Platform durante todo seu ciclo de vida.

O modelo estabelece como APIs são criadas, registradas, governadas, publicadas, consumidas e evoluídas.

---

# Visão Geral do Modelo

O API Management utiliza um modelo baseado em ciclo de vida controlado.

Cada API é tratada como um recurso governado que passa por estados definidos.
