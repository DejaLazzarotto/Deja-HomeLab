# 03. Organização

## Objetivo

Esta seção define a organização arquitetural do API Management dentro da Deja Platform.

O objetivo é estabelecer como a capacidade é estruturada internamente, quais responsabilidades existem e como os componentes se relacionam para suportar o gerenciamento completo das APIs.

Ele atua entre a definição das APIs e sua execução operacional.
