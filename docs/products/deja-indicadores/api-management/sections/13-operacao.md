# 13. Operação

## Objetivo

Esta seção define o modelo operacional do API Management dentro da Deja Platform.

O objetivo é estabelecer como a capacidade é administrada em ambiente operacional, garantindo disponibilidade, controle, manutenção, acompanhamento e evolução contínua das APIs.

---

# Visão Geral

A operação do API Management representa o conjunto de processos necessários para manter o ecossistema de APIs funcionando de forma confiável.

O modelo operacional contempla:

- administração;
- monitoramento;
- manutenção;
- suporte;
- governança;
- evolução.
