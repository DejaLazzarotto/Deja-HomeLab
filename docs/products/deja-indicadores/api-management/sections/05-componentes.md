# 05. Componentes

## Objetivo

Esta seção define os componentes arquiteturais que compõem o API Management dentro da Deja Platform.

A organização dos componentes segue o princípio de separação de responsabilidades, permitindo evolução independente, governança clara e integração controlada com os demais elementos da plataforma.
