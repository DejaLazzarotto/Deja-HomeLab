# API Management — Deja Platform

## Visão Geral

O API Management estabelece a capacidade institucional responsável pelo gerenciamento completo do ciclo de vida das APIs da Deja Platform.

Enquanto o API Gateway representa a camada de exposição, roteamento e execução das APIs, o API Management define os processos, políticas, controles e mecanismos necessários para governar essas APIs como recursos arquiteturais oficiais da plataforma.

---

## Objetivo

O objetivo do API Management é garantir que todas as APIs da Deja Platform sejam:

- projetadas de forma consistente;
- registradas e catalogadas;
- versionadas;
- publicadas de maneira controlada;
- consumidas por clientes autorizados;
- monitoradas operacionalmente;
- governadas durante todo seu ciclo de vida.

---

## Escopo

O API Management cobre:

- ciclo de vida de APIs;
- catálogo e descoberta;
- publicação;
- consumo;
- políticas de uso;
- governança;
- métricas;
- analytics;
- controle de versões;
- relacionamento com consumidores;
- integração com componentes institucionais.

---

## Relação com API Gateway

O API Management e o API Gateway possuem responsabilidades complementares.

O API Management é responsável por:

- definir;
- organizar;
- governar;
- controlar;
- acompanhar APIs.

O API Gateway é responsável por:

- receber chamadas;
- aplicar políticas em runtime;
- encaminhar requisições;
- executar contratos publicados.
