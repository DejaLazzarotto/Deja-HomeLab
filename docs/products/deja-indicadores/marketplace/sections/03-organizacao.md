# 3. Organização

## Objetivo

Esta seção descreve a organização arquitetural do Marketplace dentro da Deja Platform.

O objetivo é definir como a capacidade é estruturada, quais são seus domínios internos e como suas responsabilidades são distribuídas.

---

## Visão organizacional

O Marketplace é organizado como uma capacidade transversal da Deja Platform.

Ele possui responsabilidades relacionadas a:

- catálogo;
- publicação;
- distribuição;
- consumo;
- governança;
- integração com capacidades institucionais.
