# 13. Operação

## Objetivo

Esta seção define os aspectos operacionais do Developer Portal da Deja Platform.

O objetivo é estabelecer os requisitos necessários para manter a capacidade disponível, confiável, monitorada e alinhada aos padrões operacionais da plataforma.

---

# Papel operacional

O Developer Portal é uma capacidade transversal que deve operar continuamente como ponto oficial de interação com consumidores de APIs.

A operação deve garantir:

- disponibilidade;
- desempenho;
- segurança;
- integridade das informações;
- continuidade operacional.
