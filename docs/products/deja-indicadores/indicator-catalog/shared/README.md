# Componentes Compartilhados

## Visão Geral

O diretório **shared/** concentra os componentes reutilizáveis utilizados pela documentação dos indicadores da Deja Indicadores.

Seu objetivo é evitar duplicação de conteúdo, padronizar a documentação e facilitar a manutenção do Catálogo Oficial de Indicadores.

Todos os indicadores deverão utilizar, sempre que aplicável, os componentes definidos neste diretório.

---

# Conteúdo

O diretório é composto pelos seguintes documentos:

- **glossary.md** — Glossário institucional utilizado pelos indicadores.
- **templates/** — Templates oficiais para documentação dos indicadores e de seus cálculos.

Novos componentes compartilhados poderão ser adicionados futuramente, mantendo compatibilidade com a estrutura institucional.

---

# Objetivos

Os componentes compartilhados possuem como principais objetivos:

- padronizar a documentação;
- reduzir redundâncias;
- facilitar revisões;
- simplificar a criação de novos indicadores;
- manter consistência terminológica;
- apoiar a evolução contínua do catálogo.

---

# Utilização

Toda documentação de indicadores deverá utilizar preferencialmente os modelos e convenções definidos neste diretório.

Caso seja necessária alguma exceção, ela deverá ser formalmente documentada e aprovada pela governança do produto.

---

# Evolução

Os componentes compartilhados poderão evoluir ao longo do tempo para atender novas necessidades da Deja Indicadores.

Toda alteração deverá preservar a compatibilidade com os indicadores já documentados e manter a consistência institucional do catálogo.
