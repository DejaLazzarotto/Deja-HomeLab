# IND-001 — Faturamento

## Visão Geral

O indicador **IND-001 — Faturamento** representa o primeiro indicador oficial da Deja Indicadores.

Seu objetivo é medir o valor monetário das vendas realizadas em um determinado período, fornecendo uma visão consolidada da receita gerada pela organização.

Este indicador constitui uma das principais métricas de acompanhamento empresarial e serve como base para diversos outros indicadores analíticos, como Ticket Médio, Margem Bruta, Lucratividade, Crescimento de Receita e Participação por Cliente, Produto ou Região.
