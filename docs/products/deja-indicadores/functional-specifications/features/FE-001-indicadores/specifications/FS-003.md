# FS-003 — Filtragem de Indicadores

## Identificação

| Campo | Valor |
|-------|-------|
| Functional Specification | FS-003 |
| Feature | FE-001 — Indicadores |
| Functional Function | FF-003 |
| Nome | Filtragem de Indicadores |
| Status | Em elaboração |
| Versão | 1.0 |

---

# Objetivo

Definir o comportamento funcional da aplicação de filtros sobre o catálogo de indicadores, permitindo ao usuário restringir a visualização dos resultados de acordo com critérios específicos.

Esta especificação descreve exclusivamente o comportamento funcional da filtragem, sem definir aspectos de interface, persistência ou implementação técnica.

---

# Escopo

Esta especificação contempla:

- aplicação de filtros;
- combinação de múltiplos filtros;
- remoção individual de filtros;
- limpeza de todos os filtros;
- atualização da lista de resultados.

Não fazem parte desta especificação:

- pesquisa textual;
- ordenação;
- favoritos;
- exportação;
- pesquisa avançada.

---

# Atores

| Ator | Descrição |
|------|-----------|
| Usuário | Restringe a visualização do catálogo utilizando filtros disponíveis |

---

# Pré-condições

- O catálogo de indicadores está disponível.
- Existem filtros configurados para utilização.

---

# Pós-condições

- Apenas indicadores compatíveis com os filtros permanecem visíveis.
- O usuário pode remover ou alterar os filtros aplicados.

---

# Fluxo Principal

1. O usuário acessa os filtros disponíveis.
2. O usuário seleciona um ou mais critérios.
3. O sistema aplica os filtros.
4. O catálogo é atualizado.
5. O usuário pode alterar os filtros a qualquer momento.

---

# Fluxos Alternativos

## FA-001 — Nenhum indicador encontrado

1. Os filtros são aplicados.
2. Nenhum indicador atende aos critérios.
3. O sistema informa que não existem resultados compatíveis.

---

## FA-002 — Limpeza dos filtros

1. O usuário remove todos os filtros.
2. O sistema restaura a listagem completa do catálogo.

---

# Regras de Negócio

| Código | Regra |
|---------|-------|
| RN-001 | Apenas filtros disponíveis podem ser utilizados. |
| RN-002 | Os filtros podem ser combinados. |
| RN-003 | A remoção dos filtros restaura os resultados correspondentes. |
| RN-004 | A filtragem não altera os dados do catálogo. |

---

# Dados Funcionais

Os filtros poderão considerar, entre outros:

- categoria;
- órgão de origem;
- período;
- assunto;
- tipo de indicador;
- situação do indicador.

A definição dos filtros disponíveis é responsabilidade da administração do produto.

---

# Critérios de Aceitação

- O usuário consegue aplicar filtros.
- É possível combinar múltiplos filtros.
- A lista é atualizada após cada alteração.
- É possível remover filtros individualmente.
- É possível limpar todos os filtros.
- O sistema trata corretamente a ausência de resultados.

# Observações

A filtragem constitui um mecanismo complementar à pesquisa textual. Ambas podem ser utilizadas em conjunto, porém permanecem funcionalmente independentes e possuem especificações próprias, preservando a modularidade e a rastreabilidade da documentação institucional.
