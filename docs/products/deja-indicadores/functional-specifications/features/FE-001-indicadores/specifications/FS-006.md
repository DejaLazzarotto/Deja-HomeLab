# FS-006 — Favoritos

---

# Objetivo

Definir o comportamento funcional da gestão de indicadores favoritos, permitindo ao usuário criar e manter uma lista personalizada de indicadores para acesso rápido.

Esta especificação descreve exclusivamente o comportamento funcional da funcionalidade de favoritos, sem estabelecer requisitos de persistência, autenticação ou implementação técnica.

---

# Escopo

Esta especificação contempla:

- adicionar um indicador aos favoritos;
- remover um indicador dos favoritos;
- consultar a lista de favoritos;
- identificar visualmente indicadores marcados como favoritos.

Não fazem parte desta especificação:

- compartilhamento de favoritos;
- organização em pastas;
- favoritos públicos;
- sincronização entre usuários;
- recomendações baseadas em favoritos.

---

# Atores

| Ator | Descrição |
|------|-----------|
| Usuário | Gerencia sua lista pessoal de indicadores favoritos |

---

# Pré-condições

- O usuário possui acesso ao sistema.
- O indicador está disponível para consulta.

---

# Pós-condições

- O indicador é incluído ou removido da lista de favoritos.
- A identificação do estado de favorito é atualizada.

---

# Fluxo Principal

1. O usuário visualiza um indicador.
2. O usuário solicita adicioná-lo aos favoritos.
3. O sistema registra a preferência.
4. O indicador passa a ser identificado como favorito.
5. O usuário pode consultar posteriormente sua lista de favoritos.

---

# Fluxos Alternativos

## FA-001 — Remoção de favorito

1. O usuário solicita remover o indicador dos favoritos.
2. O sistema remove a associação.
3. O indicador deixa de ser identificado como favorito.

---

## FA-002 — Lista vazia

1. O usuário acessa seus favoritos.
2. Não existem indicadores marcados.
3. O sistema informa que a lista está vazia.

---

# Regras de Negócio

| Código | Regra |
|---------|-------|
| RN-001 | Um indicador pode estar favoritado apenas uma vez pelo mesmo usuário. |
| RN-002 | A remoção de um favorito não altera o indicador. |
| RN-003 | A lista de favoritos pertence exclusivamente ao usuário. |
| RN-004 | A identificação de favorito deve permanecer consistente em todas as consultas do catálogo. |

---

# Dados Funcionais

Cada favorito referencia um indicador existente e poderá apresentar, no mínimo:

- código;
- nome;
- categoria;
- data da última atualização.

---

# Critérios de Aceitação

- O usuário consegue adicionar um indicador aos favoritos.
- O usuário consegue remover um indicador dos favoritos.
- A lista de favoritos apresenta apenas indicadores marcados.
- Indicadores favoritos são identificados visualmente no catálogo.
- O sistema trata corretamente listas vazias.

# Observações

A funcionalidade de favoritos tem como objetivo facilitar o acesso recorrente aos indicadores mais relevantes para cada usuário. Funcionalidades avançadas, como organização em coleções, compartilhamento ou sincronização entre ambientes, deverão ser documentadas em Functional Specifications específicas.
