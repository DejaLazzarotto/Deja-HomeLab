# FS-004 — Ordenação de Indicadores

## Identificação

| Campo | Valor |
|-------|-------|
| Functional Specification | FS-004 |

| Functional Function | FF-004 |
| Nome | Ordenação de Indicadores |
| Status | Em elaboração |
| Versão | 1.0 |

---

# Objetivo

Definir o comportamento funcional da ordenação do catálogo de indicadores, permitindo que o usuário organize a sequência de apresentação dos resultados conforme critérios disponíveis.

Esta especificação descreve exclusivamente o comportamento funcional da ordenação, permanecendo independente da implementação técnica e da interface de usuário.

---

# Escopo

Esta especificação contempla:

- seleção do critério de ordenação;
- alteração da direção da ordenação;
- atualização da lista de indicadores;
- restauração da ordenação padrão.

Não fazem parte desta especificação:

- pesquisa textual;
- filtros;
- favoritos;
- exportação;
- personalização permanente da ordenação.

---

# Atores

| Ator | Descrição |
|------|-----------|
| Usuário | Organiza a apresentação dos indicadores conforme sua necessidade |

---

# Pré-condições

- O catálogo de indicadores está disponível.
- Existe pelo menos um indicador disponível para visualização.

---

# Pós-condições

- A lista é apresentada conforme o critério de ordenação escolhido.
- O usuário pode alterar a ordenação a qualquer momento.

---

# Fluxo Principal

1. O usuário acessa as opções de ordenação.
2. O usuário seleciona um critério.
3. O sistema reorganiza os indicadores.
4. A nova sequência é apresentada ao usuário.
5. O usuário pode alterar ou restaurar a ordenação padrão.

---

# Fluxos Alternativos

## FA-001 — Critério padrão

1. O usuário solicita a restauração da ordenação padrão.
2. O sistema reorganiza a lista conforme a configuração padrão do produto.

---

## FA-002 — Alteração da direção

1. O usuário altera a direção da ordenação.
2. O sistema reorganiza os indicadores em ordem crescente ou decrescente, conforme aplicável.

---

# Regras de Negócio

| Código | Regra |
|---------|-------|
| RN-001 | Apenas critérios de ordenação disponíveis podem ser utilizados. |
| RN-002 | A ordenação não altera os dados do catálogo. |
| RN-003 | A ordenação deve preservar os resultados da pesquisa e dos filtros já aplicados. |
| RN-004 | A ordenação padrão deve estar sempre disponível para restauração. |

---

# Dados Funcionais

Exemplos de critérios de ordenação:

- nome;
- código;
- categoria;
- data de atualização;
- órgão responsável.

A disponibilidade de cada critério depende da configuração do produto.

---

# Critérios de Aceitação

- O usuário consegue selecionar um critério de ordenação.
- A lista é reorganizada imediatamente após a seleção.
- É possível alterar a direção da ordenação quando aplicável.
- A pesquisa e os filtros permanecem preservados após a ordenação.
- O usuário consegue restaurar a ordenação padrão.

# Observações

A ordenação atua exclusivamente sobre a forma de apresentação dos indicadores recuperados. Ela não modifica o conjunto de resultados obtidos pela pesquisa ou pelos filtros, preservando a separação de responsabilidades entre as funcionalidades da Feature FE-001.
